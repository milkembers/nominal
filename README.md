# 🌙🌸 nominal

![GitHub License](https://img.shields.io/github/license/milkembers/nominal?style=for-the-badge)

a minimal, dark theme with a pop of colour that hopes to improve the design - at least a little bit

![preview](https://milkembers.github.io/nominal/assets/prev.png?)

> [!IMPORTANT]  
> the theme looks a bit different post-app update, but annoyance removal and some formatting still works... will adapt it eventually

## features

- cute accent colours for checkboxes and selections
- blurred context menus and backdrops
- hides many annoyances like the nitro home, shop, quests, and welcome stickers
- ~~nitro colour theme friendly~~ (needs a little work)

## install

> [!IMPORTANT]  
> make sure to enable dark mode in settings for the theme to apply properly

### Vencord (or client without local theme folder)

@import this link, or paste it in your themes tab > online themes:

```
https://milkembers.github.io/nominal/nominal.min.css
```

### in-browser / web app

follow this link to [install with Stylus](nominal.user.css)

> [!NOTE]
> limitations prevent the Stylus theme from hiding annoyances
